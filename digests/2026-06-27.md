### [A hardware-safety-gated system for LLM-written native ARTIQ control code on a trapped-ion platform](https://arxiv.org/abs/2606.27231v1)
**Authors:** Duanyang Wang, Lu Qi, Yuanheng Xie | **Published:** 2026-06-25

**Core Problem:** Autonomous laboratory experiments using LLM agents raise safety concerns due to the potential for unchecked code to damage the apparatus.

**Approach:**

**Results:**

- The system demonstrates a robust approach to safety-gating in autonomous laboratory experiments.
