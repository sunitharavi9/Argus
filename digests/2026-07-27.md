### Skill Self-Play: Pushing the Frontier of LLM Capability with Co-Evolving Skills
**Authors:** Siyuan Huang, Pengyu Cheng, Haotian Liu | **Published:** 2026-07-24

**Core Problem:** Existing self-evolutionary methods for LLM training face a dilemma between task diversity and verification reliability.

**Approach:**
- Agent skills are identified as a middle ground to reconcile this tension.
- Each skill ensures deep, verifiable execution in a specific scenario.
- Dynamic routing across skills maintains open-ended task variety.

**Results:**
- Skill Self-Play (Skill-SP) is introduced as a co-evolutionary framework.
- It comprises a proposer, a selector, and a verifier to manage skills.
- The framework aims to improve LLM capability through co-evolving skills.

### The Regression Tax: Decomposing Why Skills Help and Hurt LLM Agents
**Authors:** Darshan Tank, Baran Nama | **Published:** 2026-07-24

**Core Problem:** Adding procedural skills to LLM agents can both improve and worsen their performance.

**Approach:**
- Comparing agents with and without skills across nearly 6,000 runs.
- Distinguishing between regressions (tasks solved without skills but failed with them) and residual failures.
- Identifying causes of regression, including skill description osmosis.

**Results:**
- The best performing skills outperform others primarily by regressing less, not by gaining more.
- Skill description osmosis is identified as a cause of regression.
- The study aims to understand why skills help and hurt LLM agents.

- It combines machine-checked declarations with self-improving agentic capabilities.
- The framework aims to automate research in causal inference reliably.
